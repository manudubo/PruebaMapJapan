## Cómo usar
1. Abrir `index.html` en un navegador
2. Navegar entre ciudades con el menú superior
3. Usar los botones de día para filtrar actividades en el mapa
4. Click en los markers para ver detalles

## Tecnologías
- Leaflet.js para mapas interactivos
- CARTO Dark tiles
- CSS moderno con variables y responsive design
