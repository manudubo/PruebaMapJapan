Create `keycloak/themes/japan-trip/login/error.ftl` based on KC 26.6.1 base error.ftl structure:

```freemarker
<#import "template.ftl" as layout>
<@layout.registrationLayout displayMessage=false; section>
    <#if section="header">
        ${msg("errorTitle")}
    <#elseif section="form">
        <div id="kc-error-message">
            <p class="instruction">${message.summary?no_esc}</p>
            <#if skipLink??>
            <#else>
                <p>
                    <#if client?? && client.baseUrl?has_content>
                        <a id="backToApplication" href="${client.baseUrl}">${msg("backToApplication")}</a>
                    </#if>
                </p>
            </#if>
        </div>
    </#if>
</@layout.registrationLayout>
```

Key notes for error.ftl:
- `displayMessage=false` — the layout macro's own message area is suppressed; the error message is rendered inline in the form section via `${message.summary?no_esc}`
- `?no_esc` — KC sanitizes message.summary before passing it to the template; using `?no_esc` renders the pre-sanitized HTML correctly
- `skipLink??` — optional variable; when absent (normal error), the back link is shown
- `client.baseUrl` — optional; only show back link when client context is available
- `${msg("errorTitle")}` → "Lo sentimos..." (from messages_es.properties)
- `${msg("backToApplication")}` → "« Volver a la aplicación" (from messages_es.properties)
