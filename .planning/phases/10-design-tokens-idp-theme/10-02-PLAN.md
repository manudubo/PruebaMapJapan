<objective>
Update all 7 TypeScript source files that reference old CSS token names in inline style strings. After Plan 01 renames the tokens in main.css, these files would silently fall through to their hardcoded fallback hex values — dark mode would stop working for the navbar, search bar, auth guard, and other components. This plan updates only the token name strings inside var() calls; fallback hex values are preserved.

Purpose: Close the dark-mode regression gap. TypeScript does not parse CSS-in-string literals at compile time, so no compile error warns about stale token names.
Output: 7 .ts files with --jp-* token names throughout all inline CSS strings.
</objective>
