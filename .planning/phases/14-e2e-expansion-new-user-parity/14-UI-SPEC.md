## Component Specification — Empty-State CTA Button

This section is the primary deliverable. It defines the single UI element introduced in this phase.

### Element identity

| Property | Value |
|----------|-------|
| Element | `<button>` |
| `id` | `empty-state-create-btn` |
| CSS classes | `btn btn-primary` |
| Parent | `.trips-empty` div (already exists, created in `renderGrid()` when `trips.length === 0`) |
| Insertion point | Appended after the two existing `<p>` elements in the empty-state branch |

### Visual appearance

- Background: `var(--jp-accent)` — `#0071e3` light / `#0a84ff` dark
- Border: `1px solid var(--jp-accent)` (collapses to button background — same as `.btn-primary`)
- Text color: `var(--jp-white)` — `#ffffff`
- Border-radius: `var(--jp-radius)` — `0` (project uses flat/square corners throughout)
- Font: 14px / weight 500 / Inter (inherits from `.btn`)
- Min-height: 36px (from `.btn`)
- Padding: `8px 16px` (from `.btn`)
- Icon: inline SVG plus-sign, `width="15" height="15"`, `stroke-width="2.5"`, `aria-hidden="true"` — same icon as `#new-trip-btn` in `dashboard.html:171-174`
- Icon gap: `gap: 6px` — pre-existing `.btn` rule, not introduced by this spec
- Margin-top: `16px` above the button (separating from the preceding paragraph)

### Hover state

- Background: `var(--jp-accent-hover)` — `#0077ed` light / `#409cff` dark
- Border: `1px solid var(--jp-accent-hover)`
- Transition: `background-color 0.15s ease, border-color 0.15s ease` (from `.btn`)

### Focus state

- Outline: `2px solid var(--jp-accent)`, `outline-offset: 2px` (from `:focus-visible` rule in `main.css:1857-1860`)

### Interaction

| Event | Behavior |
|-------|----------|
| click | Calls `openCreateForm()` — same handler as `#new-trip-btn` |
| keyboard Enter/Space | Same as click (native `<button>` semantics) |

### Accessibility

- Element is a native `<button>` — no `role` needed
- No `aria-label` needed: visible text label is sufficient
- Icon has `aria-hidden="true"`
- `type="button"` — not a form submit; must set this attribute explicitly to prevent accidental form submission

### Coarse pointer (touch) target

`.btn` has `min-height: 36px`. The `@media (pointer: coarse)` block in `main.css:1900-1905` targets `.day-btn`, `.legend-action-btn`, `.calendar-btn`, `.nav-link`, `.theme-toggle` — `.btn` is not in that list, so `min-height` stays 36px on touch. This is acceptable because the button is wide (full label), providing a large tap target by width.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | "Create your first trip" |
| Empty state heading | (none — no heading in `.trips-empty`) |
| Empty state body line 1 | "You don't have any trips saved yet." (existing, unchanged) |
| Empty state body line 2 | Remove: "Create your first itinerary with the button above!" — this text is now obsolete because the CTA is inline. Replace with nothing (delete `p2`). |
| Button label | "Create your first trip" |
| Error state | Not applicable — this button has no independent error state; errors surface via the existing `create-trip-overlay` form flow |
| Destructive confirmation | Not applicable — no destructive actions in this element |

**Rationale for p2 removal:** The second paragraph ("Create your first itinerary with the button above!") instructs the user to look for a button elsewhere. Once the CTA is embedded in the empty state, this instruction is wrong and must be removed to avoid contradictory copy.

Source: D-01 in `14-CONTEXT.md`; UX-03 in `REQUIREMENTS.md`
