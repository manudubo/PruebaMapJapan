<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API response → DOM | Trip detail data (city names, day labels, activity names, hotel names, day colors) enters the DOM here |
| Leaflet popup HTML → bindPopup | Popup HTML string crosses from JS template into Leaflet's innerHTML setter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | tripDetail.ts tab/day/legend render (SEC-01) | mitigate | All text set via textContent (setText); styles via style.setProperty (setStyle) — HTML interpretation impossible |
| T-06-02 | Tampering | buildPopup / buildHotelPopup (SEC-02) | mitigate | DOMPurify.sanitize() applied to the full HTML string before bindPopup() call — strips any injected script/event handlers |
| T-06-03 | Tampering | showError message injection | mitigate | setText(errorEl, message) — error messages are plain text, not HTML-rendered |
| T-06-04 | Tampering | createMarkerIcon label (optional activity string) | mitigate | Numeric labels are Number → String (safe); user-string optional labels sanitized via DOMPurify single-string sanitize or restricted to numeric-only |
</threat_model>
