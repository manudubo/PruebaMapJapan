```typescript
export function validateAudience(aud: string | string[] | undefined, valid: string[]): boolean {
  if (!aud) return false;
  const audArray = Array.isArray(aud) ? aud : [aud];
  return audArray.some((a) => valid.includes(a));
}
```

**Change 2 — Update verifyJwt to use the helper:**

Find the audience validation block at lines 192-200 (the `validAudiences` const and the if/else block). Replace it with:

```typescript
const validAudiences = ['japan-trip-frontend'];
const aud = payload.aud;

  throw new Error(`JWT audience not accepted: ${JSON.stringify(aud)}`);
}
```

Note: the `if (aud)` guard is removed intentionally — `validateAudience` returns false for undefined, so the throw now also covers the case where `aud` is absent entirely, which is correct behavior (a token without an audience claim should be rejected).
