```typescript
function cspPlugin(): Plugin {
  const keycloakUrl = process.env['VITE_KEYCLOAK_URL'] ?? 'http://localhost:8080';
  const csp = [
    "default-src 'none'",
    "script-src 'self' 'unsafe-inline' https://unpkg.com",
    "style-src 'self' 'unsafe-inline' https://unpkg.com",
    "img-src 'self' data: https://*.basemaps.cartocdn.com https://*.tile.openstreetmap.org https://cdn-icons-png.flaticon.com",
    `connect-src 'self' https://api.allorigins.win https://corsproxy.io https://api.open-meteo.com https://nominatim.openstreetmap.org ${keycloakUrl}`,
    "font-src 'self' https://fonts.gstatic.com",
    `frame-src 'self' ${keycloakUrl}`,
    "manifest-src 'self'",
    "worker-src 'self'",
  ].join('; ');

  return {
    name: 'csp-meta',
    transformIndexHtml(html: string): string {
      return html.replace(
        '<head>',
        `<head>\n  <meta http-equiv="Content-Security-Policy" content="${csp}">`,
      );
    },
  };
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → external origins | CSP meta tag restricts which external origins the browser may contact, load scripts/styles from, or iframe |
| meta tag → frame-ancestors | meta CSP cannot enforce frame-ancestors (clickjacking protection requires HTTP response header) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-03-01 | Tampering / XSS escalation | All 13 HTML pages | mitigate | CSP meta tag restricts connect-src, img-src, frame-src; second-line-of-defense even when DOM sinks are closed (per D-05); limits attacker's ability to exfiltrate data even if an XSS sink is found |
| T-20-03-02 | Tampering / script-src bypass via 'unsafe-inline' | script-src directive | accept | All 13 pages require 'unsafe-inline' for FOUC-prevention inline scripts (confirmed in RESEARCH.md); 'unsafe-inline' neutralizes CSP's script injection protection; connect-src/img-src/frame-src containment remains valuable; nonce-based approach deferred to a future phase |
| T-20-03-03 | Tampering / Clickjacking | frame-ancestors (absent from meta CSP) | accept | frame-ancestors is unsupported in meta CSP tags (only HTTP response headers); Vite meta approach cannot enforce it; mitigation via HTTP header in a future phase when edge/CDN response headers are configurable |
| T-20-03-04 | Tampering / CSP policy escape via keycloakUrl injection | frame-src + connect-src using VITE_KEYCLOAK_URL | mitigate | keycloakUrl read from process.env at Vite build time; defaults to localhost:8080; production build reads VITE_KEYCLOAK_URL from CI environment variable set by trusted CI pipeline — attacker cannot influence the built CSP string |
</threat_model>
