|-----------|----------|-----------|-------------|-----------------|
| T-20-01-01 | Spoofing | OTP generation (auth.ts:123 — Math.random) | mitigate | Replace Math.random (predictable PRNG — seed recoverable from timestamp) with crypto.getRandomValues (CSPRNG); attacker cannot predict OTP sequence from observation |

| T-20-01-03 | Information Disclosure | KC_ADMIN_CLIENT_SECRET in Cloudflare Worker binding | mitigate | Remove cloudflare_worker_secret resource; credential no longer bound in deployed Worker environment; cannot be exfiltrated via Worker execution |
| T-20-01-04 | Information Disclosure | Modulo bias in Uint32Array[0] % 1_000_000 | accept | Bias < 0.023% (values 4,294,000,000–4,294,967,295 bias OTPs 0–967,295); negligible for 6-digit OTP with 5-attempt lockout; rejection sampling adds complexity with no practical security benefit at this OTP length |
