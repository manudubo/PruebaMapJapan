No other lines change. The `nodejs_compat` flag on line 4 stays. Setting `compatibility_date = "2024-09-23"` with an existing `nodejs_compat` flag automatically activates `nodejs_compat_v2`, which bundles Node.js built-in polyfills (`events`, `fs`, `stream`, `path`, `os`, `util`, `net`, `tls`, etc.) as first-class modules — eliminating the 25 "Could not resolve" errors from `pg-cloudflare` and related packages. Per D-05.

**backend/package.json — three edits in `dependencies`, one in `devDependencies`:**

In `dependencies`:
- `"drizzle-orm": "^0.38.3"` → `"drizzle-orm": "^0.45.2"`
  - Closes GHSA-gpj5-g38j-94v9 (HIGH: SQL injection via `sql.identifier()` and `sql.as()`).
  - RQBv1 API (`db.query.trips.findFirst({ with: {...} })`, `eq`, `and`, `asc`, etc.) is unchanged through 0.45.x — removal only occurs in 1.0.x (separate dist-tag).
  - npm labels this "breaking change" because of the SQL injection patch, not an API surface change. Per D-08.
- `"hono": "^4.6.17"` → `"hono": "^4.12.32"`
  - Fixes 17 HIGH hono advisories affecting Lambda/ALB adapters, JSX SSR, cookie helpers — none of which this CF Workers backend uses.
  - Fix available via `npm audit fix` (no `--force` required).
  - Required for ROADMAP criterion #5 "0 HIGH or CRITICAL". Per 21-RESEARCH.md Open Question 1 (beyond D-08 scope but necessary for the success criterion).

In `devDependencies`:
- `"drizzle-kit": "^0.30.1"` → `"drizzle-kit": "^0.31.10"`
  - Aligns drizzle-kit major version with drizzle-orm 0.45.x to prevent `db:generate` schema drift warnings (Pitfall 4 in 21-RESEARCH.md).
  - This is a dev-only tool; no production impact.
