Read `keycloak/docker-compose.yml` first. Make two changes:

**Change 1: Add Mailpit service** between the `keycloak:` service and the `volumes:` section. Follow the postgres service block structure (image → ports → restart). Mailpit needs no environment, volumes, or depends_on:

```yaml
  mailpit:
    image: axllent/mailpit:v1.29
    ports:
      - "1025:1025"
      - "8025:8025"
    restart: unless-stopped
```

**Change 2: Add KC healthcheck** to the `keycloak:` service block. The KC container exposes `/health/ready` when fully started (verified in `keycloak/apply-local-settings.sh`). Add after the `depends_on:` block:

```yaml
    healthcheck:
      test: ["CMD-SHELL", "curl -sf http://localhost:8080/health/ready || exit 1"]
      interval: 10s
      timeout: 5s
      retries: 15
      start_period: 30s
```

The `start_period: 30s` gives KC time to initialize before healthcheck failures count toward retries.

IMPORTANT: Do NOT remove `--import-realm` from the `command:` line yet. That happens in Plan 6 only after `terraform apply` is confirmed successful (D-07 sequencing).

Final docker-compose.yml should have services in order: postgres → keycloak → mailpit, then volumes section.
