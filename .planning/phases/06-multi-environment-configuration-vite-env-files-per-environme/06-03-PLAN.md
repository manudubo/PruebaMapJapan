Create `terraform/keycloak/flows.tf` with the following resources in dependency order:

**1. Top-level authentication flow:**

```hcl
resource "keycloak_authentication_flow" "browser_passkey" {
  realm_id    = keycloak_realm.japan_trip.id
  alias       = "browser-passkey"
  description = "Browser flow with WebAuthn passkey as first factor (passwordless)"
  provider_id = "basic-flow"
}
```

**2. auth-cookie execution (ALTERNATIVE in top-level flow):**

```hcl
resource "keycloak_authentication_execution" "cookie" {
  realm_id          = keycloak_realm.japan_trip.id
  parent_flow_alias = keycloak_authentication_flow.browser_passkey.alias
  authenticator     = "auth-cookie"
  requirement       = "ALTERNATIVE"
  priority          = 10
}
```

**3. passkey-forms subflow (ALTERNATIVE in top-level flow, priority 20):**

```hcl
resource "keycloak_authentication_subflow" "passkey_forms" {
  realm_id          = keycloak_realm.japan_trip.id
  alias             = "passkey-forms"
  description       = "Username + WebAuthn passwordless"
  parent_flow_alias = keycloak_authentication_flow.browser_passkey.alias
  provider_id       = "basic-flow"
  requirement       = "ALTERNATIVE"
  priority          = 20
}
```

**4. auth-username-form execution (REQUIRED in passkey-forms subflow, priority 10):**

```hcl
resource "keycloak_authentication_execution" "username_form" {
  realm_id          = keycloak_realm.japan_trip.id
  parent_flow_alias = keycloak_authentication_subflow.passkey_forms.alias
  authenticator     = "auth-username-form"
  requirement       = "REQUIRED"
  priority          = 10
}
```

**5. webauthn-authenticator-passwordless execution (REQUIRED in passkey-forms subflow, priority 20):**

```hcl
resource "keycloak_authentication_execution" "webauthn_passwordless" {
  realm_id          = keycloak_realm.japan_trip.id
  parent_flow_alias = keycloak_authentication_subflow.passkey_forms.alias
  authenticator     = "webauthn-authenticator-passwordless"
  requirement       = "REQUIRED"
  priority          = 20
}
```

**6. webauthn-register-passwordless required action:**

```hcl
resource "keycloak_required_action" "webauthn_register_passwordless" {
  realm_id       = keycloak_realm.japan_trip.realm
  alias          = "webauthn-register-passwordless"
  enabled        = true
  default_action = false
  name           = "Webauthn Register Passwordless"
}
```

Note: `realm_id` for `keycloak_required_action` uses `.realm` (the realm name string), not `.id`. This matches the provider schema from RESEARCH.md Code Examples.

IMPORTANT: Do NOT set `browser_flow = "browser-passkey"` in the realm resource. That binding switch is Phase 7 (KC-02). The flow is created here so it exists in KC, but is not activated.

Do NOT use `depends_on` for execution ordering — use `priority` argument only (KC 26 pattern per RESEARCH.md).
