## Milestone Summary

**Key Decisions:**

- Keep DEV-gated `console.debug`/`console.warn` logging added during Phase 14 debugging (silent in production builds, useful for future auth debugging)
- `keycloak-js` `getToken()`: only call `updateToken(30)` when `isTokenExpired(30)` is true — avoids a spurious throw when KC issues a token with no refresh token (e.g. after silent-check-sso)
- `tsx watch` does not auto-load Wrangler's `.dev.vars` the way it loads `.env` — `dev.ts` now calls `dotenv.config({ path: '.dev.vars' })` explicitly
- Phase 12 `import=true` deviation accepted as a documented override rather than blocking close — KC volume non-persistence is an environment quirk, not a Terraform design flaw

**Issues Resolved:**

- Backend `lat`/`lng` validation rejected valid geocoded coordinates (`z.string()` → `z.coerce.string()`)
- Geocoder widget pattern required explicit button click, previously assumed implicit on input fill
- `npm run dev` required `npm install` to pull in `concurrently` (caught in Phase 12 verification, resolved before Phase 13)
- Stale `REQUIREMENTS.md` traceability (all 30 reqs unchecked despite phases verified) caught and corrected at milestone close, mirroring the same antipattern flagged in the v2.0 retrospective

**Issues Deferred:**

- Phase 11 has no `11-VERIFICATION.md` file (gap in artifact trail, not blocking — corroborated by live codebase evidence: `toast.ts`, `ApiError`, retrofit all present and tested)
- 7 other pre-existing failing E2E specs (idp-theme, otp, passkeys ×3, public-sharing, session-management) — not in v3.0 scope, not investigated this milestone

**Technical Debt Incurred:**

- None new. Pre-existing Terraform drift (protocol mapper replacements, email_theme) noted in Phase 12 remains open, carried from v2.0.
