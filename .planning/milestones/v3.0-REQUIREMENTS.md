  - **Outcome:** Shipped Phase 13. `verifyJwt` retry-on-signature-failure with DoS guard, unit-tested.
- [x] **SEC-03**: KC client uses strict redirect URIs, no wildcards
  - **Outcome:** Shipped Phase 12. 8 explicit redirect URIs + 4 post-logout URIs, dev/prod separated.
- [x] **SEC-04**: Hono responses include CSP, X-Frame-Options, HSTS headers
  - **Outcome:** Shipped Phase 13. `security.ts` middleware, all 4 headers unconditional.
- [x] **SEC-05**: E2E assertion — token with `aud: account` only returns 401
  - **Outcome:** Shipped Phase 13. `api.spec.ts` wrong-audience test.
