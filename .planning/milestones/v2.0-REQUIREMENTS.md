## v2.0 Requirements

### Infrastructure (INFRA)

- [x] **INFRA-01**: Terraform Keycloak module manages all realm config as HCL — `keycloak_realm`, `keycloak_openid_client`, auth flow executions, `keycloak_required_action`; `realm-export.json` becomes read-only reference snapshot; `--import-realm` removed from docker-compose once local apply confirmed

- [x] **INFRA-02**: Terraform Cloudflare module manages Worker secrets (`RESEND_API_KEY`, `KC_ADMIN_CLIENT_SECRET`) via `cloudflare_worker_secret`; no plaintext secrets in `wrangler.toml`
  - **Outcome:** Shipped Phase 6. CF module created; applied in CI/CD (Windows App Control blocked local binary execution — deferred to pipeline).
- [x] **INFRA-03**: Mailpit v1.29 replaces MailHog in docker-compose as local SMTP; MailHog removed
  - **Outcome:** Shipped Phase 6. Mailpit on ports 1025/8025; REST API at `/api/v1/messages` verified.

  - **Outcome:** Shipped Phase 7. VERIFY_EMAIL + Mailpit SMTP delivery confirmed via Admin API smoke test.
- [x] **KC-02**: `browserFlow` switched from `"browser"` to `"browser-passkey"` via Terraform — password-forms ALTERNATIVE branch exists before switch
  - **Outcome:** Shipped Phase 7. `browser_flow = "browser-passkey"` in terraform.tfstate; password-forms ALTERNATIVE present.
- [x] **KC-03**: `webauthn-register-passwordless` Required Action registered in realm with `defaultAction: false`
  - **Outcome:** Shipped Phase 7. Count=1 in flows.tf; no duplicate; campaign triggers via AIA.
- [x] **KC-04**: Theme i18n — `messages_es.properties` created; `locales=es,en` in `theme.properties`; FreeMarker overrides for `login.ftl`, `login-otp.ftl`, `verify-email.ftl`, `error.ftl`
  - **Outcome:** Shipped Phase 7. All 5 theme files exist; `locales=es,en` confirmed.

### Passkeys (PASS)

- [x] **PASS-04**: Post-login passkey campaign — `initKeycloak()` completion triggers WebAuthn device capability check; if capable and no cookie `pnk_{userId}`, redirect via `kc_action=webauthn-register-passwordless`; per-device opt-out cookie written with `max-age=2592000`, `SameSite=Strict`
  - **Outcome:** Shipped Phase 8. `checkPasskeyCampaign()` in dashboard.ts; 3 unit tests pass; cookie written before `keycloak.login`.
- [x] **PASS-05**: Email OTP fallback — Worker endpoints `POST /api/auth/otp-request` and `POST /api/auth/otp-verify`; 6-digit OTP, SHA-256 hash, 10-min TTL, single-use, max 5 attempts; timing-safe HMAC-SHA256 + XOR accumulator
  - **Outcome:** Shipped Phase 8. OTP delivered via Mailpit, replay blocked, all auth.test.ts cases pass.
- [x] **PASS-06**: Guard against deleting last credential — profile page delete flow checks remaining credential count; shows error if would leave user with zero credentials
  - **Outcome:** Shipped Phase 8. `credentialCount === 1` guard + modal in profile.ts.
- [x] **PASS-07**: `UPDATE_PASSWORD` Required Action forced post-OTP verify ONLY when device does NOT support WebAuthn passkeys
  - **Outcome:** Shipped Phase 8. `!capable` guard before `keycloak.login(UPDATE_PASSWORD)`; 2 unit tests.

  - **Outcome:** Shipped Phase 7. `japan-trip-worker` client with manage-users role; `KC_ADMIN_CLIENT_SECRET` in .dev.vars.
