The module must:

1. **Render activities list** inside `container`:
   - Empty state: "Sin actividades. Agregá la primera." when `day.activities.length === 0`
   - Each activity as `.activity-row`:
     ```html
     <div class="activity-row">
       <button class="btn-icon" title="Subir">▲</button>
       <button class="btn-icon" title="Bajar">▼</button>
       <span class="activity-name">Activity Name</span>
       <span class="activity-time">HH:MM</span>  <!-- hidden if time is null -->
       <button class="btn btn-secondary">Editar</button>
       <button class="btn btn-danger">Eliminar</button>
     </div>
     ```
   - "Agregar actividad" button above the list

2. **Reorder buttons — disabled states** (UI-SPEC Interaction Contract):
   - ▲ button on first activity: `disabled` attribute set, `style="opacity: 0.35; cursor: default"`
   - ▼ button on last activity: `disabled` attribute set, `style="opacity: 0.35; cursor: default"`
   - Middle activities: both buttons enabled

3. **Reorder click handler** (CRITICAL — POST not PATCH):
   ```typescript
   async function handleReorder(
     activities: ApiActivity[],
     movedIndex: number,
     direction: 'up' | 'down',
     tripId: string,
     destId: string,
     dayId: string,
     container: HTMLElement,
   ): Promise<void> {
     const newActivities = [...activities];
     const swapIndex = direction === 'up' ? movedIndex - 1 : movedIndex + 1;
     [newActivities[movedIndex], newActivities[swapIndex]] = [newActivities[swapIndex], newActivities[movedIndex]];

     // Optimistic DOM reorder first (transition: transform 0.15s ease on rows)
     // Then send POST — if error, revert DOM
     try {
       const orderedIds = newActivities.map((a) => Number(a.id));
       // reorderActivities uses POST (not PATCH) — implemented in 02-02
       await reorderActivities(tripId, destId, dayId, orderedIds);
       // Re-render with new order
       renderActivitiesSection(container, { ...day, activities: newActivities }, tripId, destId);
     } catch {
       // Revert DOM to original order
       renderActivitiesSection(container, day, tripId, destId);
       // Show error below the activity row
       const errEl = document.createElement('p');
       errEl.className = 'error-msg';
       setText(errEl, 'No se pudo guardar. Verificá tu conexión e intentá de nuevo.');
       container.appendChild(errEl);
     }
   }
   ```
