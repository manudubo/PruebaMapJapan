3. **Geocoder widget behavior** inside destination modal:
   - On "Buscar lugar" click: if input looks like a Google Maps URL (`isGoogleMapsUrl(input)`), call `extractCoordsFromGoogleMapsUrl` synchronously — populate `#dest-lat`, `#dest-lng`, show "Encontrado" in results list
   - Otherwise: call `searchNominatim(query)`, show button as "Buscando…" + disabled while loading
   - On result click: populate `#dest-lat`, `#dest-lng`, set input value to `result.display_name`, hide results
   - No results: show "Sin resultados. Probá con otra búsqueda." in results div
   - Network error: show `.error-msg` "Error al buscar la ubicación. Intentá de nuevo."
   - All result text must use `setText` or `textContent` assignment — never innerHTML

4. **Form submission**:
   - `createDestination(tripId, { city_name, country, start_date, end_date, lat, lng })` for add mode
   - `updateDestination(tripId, destId, {...})` for edit mode (destId stored in module state)
   - On success: close modal, re-render destination list
   - On error: show `#dest-form-error` with "No se pudo guardar. Verificá tu conexión e intentá de nuevo."

5. **Delete flow** using existing `#confirm-overlay`:
   - "Eliminar" button: set `#confirm-title` to "¿Eliminar destino?", `#confirm-msg` to "Se eliminarán todos los días y actividades de este destino.", show overlay
   - `#confirm-delete-btn` click: call `deleteDestination(tripId, destId)`, re-render list
   - `#confirm-cancel-btn` click: hide overlay
   - Escape key: hide overlay

6. **Security invariants** (Phase 1 — must not regress):
   - Never use `innerHTML` with any user-controlled string
   - Use `setText(el, value)` for all text that originates from API responses or form inputs
   - Use `el.textContent = ` only for static literals defined in this source file

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Destination modal form → API | city_name, country, lat, lng come from user input |
| Nominatim response → DOM | display_name rendered via setText — XSS safe |
| Google Maps URL → lat/lng | Regex extracts only numeric values — no HTML rendered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Tampering | Destination form → createDestination/updateDestination | mitigate | Backend validates via CreateDestinationSchema / UpdateDestinationSchema (Zod); frontend sends known fields only |
| T-02-05-02 | Elevation of Privilege | deleteDestination | mitigate | Backend resolveDestination() verifies trip ownership before delete; 403 returned for mismatched userId |
| T-02-05-03 | Spoofing | XSS via city_name/country in DOM | mitigate | All API response values rendered via setText() — textContent assignment; Phase 1 invariant |
