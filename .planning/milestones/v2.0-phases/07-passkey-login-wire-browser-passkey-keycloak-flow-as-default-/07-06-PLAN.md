```freemarker
        ${msg("emailVerifyTitle")}

        <p class="instruction">${msg("emailVerifyInstruction1", user.email)}</p>
    <#elseif section="info">

            <br/>

    </#if>
</@layout.registrationLayout>
```

Key notes:
- `displayInfo=true` — enables the `section="info"` section (for the resend link)

- `${msg("doClickHere")}` → "Hacé clic aquí" (from messages_es.properties)
- `${msg("emailVerifyInstruction3")}` → "para reenviar el correo." (fragment, continuation of sentence)
- `${url.loginAction}` — the resend/continue URL provided by KC context

If `isAppInitiatedAction??` (AIA context), the page should also show a Cancel button linking back to the application. Add at the end of the form section:
