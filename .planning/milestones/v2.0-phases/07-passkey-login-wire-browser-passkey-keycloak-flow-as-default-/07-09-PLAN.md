Test the full VERIFY_EMAIL flow end-to-end using the KC Admin API to create a test user (avoids needing a real browser registration flow):

**Step 0 — Pre-clear Mailpit inbox:**
```bash
curl -s -X DELETE http://localhost:8025/api/v1/messages
```
Expected: 204 or empty response. Clears any stale messages so Step 4 cannot produce a false pass.

**Step 1 — Parse admin password and get admin token:**
```bash
KC_ADMIN_PASS=$(grep 'admin_password' terraform/keycloak/local.tfvars | cut -d'"' -f2)
KC_TOKEN=$(curl -s -X POST http://localhost:8080/realms/master/protocol/openid-connect/token \
  -d "grant_type=password&client_id=admin-cli&username=admin&password=${KC_ADMIN_PASS}" \
  | jq -r '.access_token')
```

**Step 2 — Create a test user with email verification required:**
```bash
curl -s -X POST http://localhost:8080/admin/realms/japan-trip/users \
  -H "Authorization: Bearer $KC_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"username":"test-verify-email","email":"test@example.com","enabled":true,"emailVerified":false,"requiredActions":["VERIFY_EMAIL"]}'
```

**Step 3 — Trigger verification email via send-verify-email:**
```bash
USER_ID=$(curl -s "http://localhost:8080/admin/realms/japan-trip/users?username=test-verify-email" \
  -H "Authorization: Bearer $KC_TOKEN" | jq -r '.[0].id')

curl -s -X PUT "http://localhost:8080/admin/realms/japan-trip/users/$USER_ID/send-verify-email" \
  -H "Authorization: Bearer $KC_TOKEN"
```

**Step 4 — Check Mailpit for the email:**
```bash
curl -s http://localhost:8025/api/v1/messages | jq '.messages[0].Subject'
```
Expected: subject contains "Verificación" or the KC email subject (may be English from KC built-in if theme is not applied to admin-triggered emails — accept either).

**Step 5 — Cleanup test user:**
```bash
curl -s -X DELETE "http://localhost:8080/admin/realms/japan-trip/users/$USER_ID" \
  -H "Authorization: Bearer $KC_TOKEN"
```

If the Mailpit API returns an empty messages array after step 4, verify that:
- Mailpit is running: `docker compose -f keycloak/docker-compose.yml ps mailpit`
- KC smtp_server block in main.tf points to `host = "mailpit"` (not localhost)
- KC realm has email sender configured (`from = "noreply@japan-trip.local"` in smtp_server)
