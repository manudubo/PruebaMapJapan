<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL params → tripDetail.ts | `?slug=` and `?tripId=` are user-controlled; slug is passed to the backend API |
| clipboard ← tripDetail.ts | `navigator.clipboard.writeText` receives a string constructed from origin + pathname + public_slug |
| DOM ← tripDetail.ts | Button text is written via setText (dom.ts), not innerHTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering | Copy-link URL construction | accept | URL is built from `window.location.origin + pathname + trip.public_slug` — public_slug comes from the authenticated API response, not from user input |
| T-03-03-02 | Information Disclosure | data-owner-only hiding | mitigate | Elements hidden via `setAttribute('hidden', '')` in slug mode before render — edit link and other owner controls not reachable via DOM in guest view |
| T-03-03-03 | XSS via button text | copy-link button feedback text | mitigate | Button text uses `setText()` from dom.ts (SEC-01 pattern) — never sets innerHTML; '¡Copiado!' and 'Copiar enlace público' are static literals |
| T-03-03-04 | Information Disclosure | public_slug in URL | accept | Public slug is the intended sharing mechanism — writing it to clipboard via the copy-link button is by design |
</threat_model>
