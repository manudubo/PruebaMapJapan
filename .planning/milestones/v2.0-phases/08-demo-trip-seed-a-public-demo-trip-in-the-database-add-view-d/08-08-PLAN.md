**Criterion 1 — OTP request/deliver (PASS-05):**

2. Start the Worker locally: `cd backend && npx wrangler dev`
3. Log in to the app at http://localhost:3000
4. Open browser DevTools Network tab

**Criterion 2 — OTP verify (PASS-05):**
1. Take the 6-digit code from Mailpit
2. Call POST /api/auth/otp-verify with body `{ "code": "XXXXXX" }` and Bearer token
3. Expected: 200 { success: true }
4. Call the same endpoint again with the same code → expected: 400 { error: 'otp_not_found' } (code is now used)

**Criterion 3 — Passkey campaign (PASS-04):**
On a WebAuthn-capable browser (Chrome/Edge on desktop):
1. Clear cookies for localhost
2. Log in to the dashboard
3. Expected: redirect to Keycloak webauthn-register-passwordless AIA
4. Press back or complete registration → verify cookie `pnk_{yourUserId}` is now set
5. Reload dashboard → no redirect (campaign is suppressed)

**Criterion 4 — Last-credential guard (PASS-06):**
1. Go to http://localhost:3000/profile.html
2. If you have exactly 1 passkey, click Delete
3. Expected: modal opens with text "You must register another passkey on another device before deleting this one." and button "Register another passkey first"
4. If you have 2+ passkeys, this check cannot be done without registering a second passkey first
