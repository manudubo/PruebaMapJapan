if (response.status === 401) {
  showToast('Session expired — redirecting to login', 'info');

  return new Promise<never>(() => { /* intentionally never resolves — prevents double-toast */ });

  throw new ApiError(response.status, envelope?.code ?? 'unknown');

CRITICAL: The em-dash in the toast message is Unicode U+2014 (`—`), NOT a hyphen-minus. The string literal must be `'Session expired — redirecting to login'` or the actual em-dash character `—`. Tests assert the exact character.

CRITICAL: The 401 block must come BEFORE the `!response.ok` block. A 401 is also `!response.ok`, so if the order is reversed, the 401 path is never reached.

CRITICAL: `return new Promise<never>(() => {})` — do NOT throw after this point. If this function throws instead, the caller's catch block fires a second "Something went wrong" toast on top of the "Session expired" toast, violating D-07.

Side effect (acceptable): caller `finally` blocks will not run when 401 fires, because the returned promise never resolves. This means the dashboard submit button stays disabled. This is acceptable — the page navigates away in 1.5 seconds before the user notices.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-03-01 | Information Disclosure | ApiError message field | mitigate | ApiError message defaults to `API error {status}` — no server response body text forwarded to UI. Frontend shows generic "Something went wrong" (D-07) via showToast, never ApiError.message. |
| T-11-03-02 | Elevation of Privilege | 401 login() redirect | accept | login() uses existing PKCE S256 flow (keycloak.ts). Redirect target is hardcoded to 'dashboard.html' — no open-redirect vector. Attacker cannot redirect to arbitrary URL via this code path. |
| T-11-03-03 | Spoofing | envelope.code from API response | accept | Frontend uses code only for logging/ApiError.code field. D-07 mandates generic messages regardless of code value — a malicious code value cannot trigger different UI behavior. |
| T-11-03-04 | Denial of Service | never-resolving Promise<never> | accept | Promise is returned, not stored globally. Caller drops the reference. GC eligible after redirect. No accumulation risk. |
</threat_model>
