## Anti-FOUC Contract (DESIGN-04)

**Status: Already satisfied. Net-new work: none.**

All 13 HTML files already contain the following pattern (RESEARCH.md §DESIGN-04 Mismatch):

```html
<!-- Critical CSS to prevent FOUC -->
<style>
  html { background: #f5f5f7; }
  html[data-theme="dark"] { background: #000; }
  body { opacity: 0; transition: opacity 0.15s ease; }
  body.ready { opacity: 1; }
</style>
<script>
  (function() {
    var theme = localStorage.getItem('theme');
    if (theme) {
      document.documentElement.setAttribute('data-theme', theme);
    } else if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      document.documentElement.setAttribute('data-theme', 'dark');
    }
  })();
</script>
```

**Contract:** The existing script is the contract. It is a superset of D-04's literal spec
(it also applies `data-theme=dark` from `prefers-color-scheme` on first visit when no
localStorage value exists). Replacing it with D-04's literal spec would be a regression.
The executor must NOT modify this script.

The inline `<style>` hardcoded hex values (`#f5f5f7`, `#000`) are structurally required
(CSS custom properties are not yet loaded when this block runs) and are explicitly excluded
from DESIGN-01 scope.
