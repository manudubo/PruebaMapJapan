Create `backend/src/middleware/security.ts` with this exact implementation:

```typescript
import type { MiddlewareHandler } from 'hono';

export const securityMiddleware: MiddlewareHandler = async (c, next) => {
  await next();
  c.header('Content-Security-Policy', "default-src 'none'");
  c.header('X-Frame-Options', 'DENY');
  c.header('Strict-Transport-Security', 'max-age=31536000; includeSubDomains');
  c.header('Referrer-Policy', 'no-referrer');
};
```

Header values (exact, per D-01, D-02, D-03, and RFC 9700 §4.2.4 gap closure):
- `Content-Security-Policy: default-src 'none'` (correct for pure JSON API; D-01)
- `X-Frame-Options: DENY` (D-02)
- `Strict-Transport-Security: max-age=31536000; includeSubDomains` (D-02)
- `Referrer-Policy: no-referrer` (Claude's Discretion per RFC 9700 §4.2.4 gap)

`await next()` MUST be called BEFORE `c.header()`. Headers set after `next()` are response-phase headers. Headers set before `next()` are request-phase and will not appear in responses.
