## Milestone Summary

**Key Accomplishments:**
1. Terraform KC realm IaC — 16 KC resources managed as HCL; `terraform apply` idempotent; `--import-realm` removed; Mailpit replaces MailHog
2. Backend hardening — `VALID_AUDIENCES` env var, `email?: string` relaxation, `email_otp_codes` migration, KC Admin client operational
3. KC auth flows + theme i18n — `browser-passkey` as default flow (password ALTERNATIVE), VERIFY_EMAIL + Mailpit SMTP, FreeMarker overrides (es/en)
4. Email OTP fallback — `POST /api/auth/otp-request` + `otp-verify`; HMAC-SHA256 timing-safe comparison; 10-min TTL; 5-attempt lockout
5. Passkey campaign — post-login WebAuthn detection, per-device cookie, last-credential guard, UPDATE_PASSWORD gated by WebAuthn support
6. Playwright real-auth E2E — OIDC PKCE globalSetup, storageState + sessionStorage replay, CDP Virtual Authenticator passkeys, Mailpit REST OTP tests

**Key Decisions:**
- Real-auth via OIDC PKCE headless Chromium (not ROPC); storageState + addInitScript workaround for Playwright bug #31108
- SKIP_REAL_AUTH CI guard — all real-auth tests gated; mocked tests unchanged in CI
- KC Admin: `client_credentials` grant with `japan-trip-worker`; manage-users CLIENT role
- OTP serial: `test.describe.configure({ mode: 'serial' })` mandatory for Mailpit inbox isolation
- CDP passkeys: `hasUserVerification` (not `haUserVerification`) — critical spelling; two-context login flow for clean KC redirect
- CF provider pinned to `>= 4.0, < 5.0` — v5 removed `cloudflare_worker_secret`
- KC postgres persistence added to docker-compose to prevent H2 in-memory realm loss on restart

**Known Gaps at Close:**
- REQUIREMENTS.md traceability table never updated during execution (all 19 v2.0 requirements show "Pending" despite being shipped — tracked in PROJECT.md Validated section)
- Verification docs for phases 02–04 marked human_needed (pre-v2.0 era, acknowledged as deferred at close)
- Phase 03 UAT resolved but audit tool flagged it

**Technical Debt Deferred to v3.0:**
- `webAuthnPolicyPasswordlessRpId` must be set to Railway prod hostname before prod passkey registration — no migration path
- Production deployment (Cloudflare + Neon + Railway) deferred to v3.0
- Real-auth E2E tests run locally only — CI requires KC in CI environment
- CF Worker secrets Terraform module could not be applied locally (Windows App Control blocked provider binary; deferred to CI/CD)
