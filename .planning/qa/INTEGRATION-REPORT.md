## How the stack run was set up

1. Start dockerd. Images: quay.io / public.ecr.aws / ghcr.io (no Docker Hub).
2. Add `127.0.0.1 integ565.localtest.me` to /etc/hosts. The TLS front listens on :443.
3. Create a self-signed cert for `smtp-sink` (`openssl req -x509 … -addext subjectAltName=DNS:smtp-sink`) in `TEST_SMTP_CERT_DIR`.
4. Copy `.env.example` to a private file and set: `PUBLIC_HOST`, `PROXY_PORT=38580`, `KC_ADMIN_PORT=38581`, `COMPOSE_PROJECT_NAME=integ565`, `EMAIL_PROVIDER=smtp`, `SMTP_HOST=smtp-sink`, `SMTP_PORT=1025`, `SMTP_SECURE=starttls`, `SMTP_USER/PASS` (Gmail-shaped), `EMAIL_FROM`, `NOMINATIM_CONTACT`. Then run `gen-secrets.sh`.
5. Export `SELFHOST_ENV_FILE`, `SELFHOST_COMPOSE_OVERRIDE=deploy/selfhost/tests/compose.test.yml`, `SELFHOST_STATE_DIR`, `TEST_SMTP_CERT_DIR`, `TEST_MAILPIT_PORT=38625`, `TEST_BUILD_PROXY=$HTTPS_PROXY`, `TEST_EXTRA_CA=/root/.ccr/ca-bundle.crt`, and `TEST_CA_FILE` (the TLS front's `root.crt`, from `docker cp …-tls-front:/data/caddy/pki/authorities/local/root.crt`).
6. Run `deploy.sh`, then `keycloak-apply.sh --yes`, then `tests/stack-e2e.sh public login cors xff backup idempotent postgres restart invite mail`.
